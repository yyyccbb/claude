# 技术经验结论

## 节拍分析
- 理论节拍取滚动窗口中"均值最小且 CV 低"的稳定段
- 停机阈值与 `--single-max` 需按线体规模调；`--single-max` 必须严格小于 `--stop-sec`
- 双通道线会出现长短交替的间隔对；相邻两间隔之和 ≈ 2 × 单件节拍
- 班次：白班 08:00–20:00，夜班 20:00–次日 08:00；生产"日" = 08:00 至次日 08:00

## 数据解析
- 产线原始 CSV 数据列多于表头列 → 用 `codecs` 原始逐行拆分，不用 `pandas.read_csv()`
- 总成结果固定在索引 5（0 基）；常见 GBK/GB18030 编码
- Excel `""=0` 为 FALSE（LibreOffice 为 TRUE）→ 未用校验段（length=0）需 `IF(length=0,1,...)` 保护
- 扫码工具跳行漏洞用 `COUNTBLANK` 回溯检查修复

## 工艺与计量
- 叠片铁芯激光焊为侧壁焊（光束平行于叠片方向），不是穿透叠层
- 0.2mm 硅钢线能量密度范围 15–30 J/mm
- 激光焊气孔机理：氢、CO、匙孔塌陷
- 旋转叠压：单片通规合格不代表叠后铁芯合格；侧壁直线度（弓形偏差）在 19 段旋转叠片中系统性累积
- 固定偏移补偿后取 abs() 会对接近 0 的测量值造成非线性折叠失真
- 托内铁芯高度波动源于随机叠加累积，而非片数差异
- 零件序列号含 26MMDD 段（如 261015）= 生产日期；与 CMM 报告时间比对得测量间隔
- CMM "元素夹角1"（MX11 程序）= 上下端面外径槽特征绕中心的夹角投影到同一平面（叠片扭转），不是轴线倾斜

## 原则与分工
- 绝不编造试验记录；走正当路径（确认性验证或如实的工艺转移说明）
- 5Why：区分产生原因链与流出原因链；根因指向系统/机制缺陷而非个人
- 废料线堵料 = 设备部主责、制造协助（不是反过来）
